# Data Cleaning

This project focuses on preparing a dataset for analysis. I worked with an original dataset, checked and cleaned the data, and created a cleaned version for further use.

## What I Worked On

- Reviewed the original dataset
- Checked the data structure
- Cleaned the dataset
- Prepared the cleaned data for analysis

## Tools Used

- Python
- Pandas
- Jupyter Notebook
- Microsoft Excel

## Files

- `raw_dataset.xlsx` — Original dataset
- `cleaned_dataset.xlsx` — Cleaned dataset
- `data_cleaning.ipynb` — Jupyter Notebook used for the cleaning work
- `data_cleaning.py` — Python source code

## Purpose

The purpose of this project was to practice data cleaning and preparation before performing further analysis.
