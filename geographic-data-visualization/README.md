# Geographic Data Visualization

This project is part of my Big Data Analytics coursework at United International University (UIU).

The project focuses on working with geographic data using Python and creating interactive visualizations.

## What I Worked On

- Geographic data cleaning and preparation
- Latitude and longitude analysis
- Geographic data visualization
- Interactive point mapping
- Heatmap visualization
- Scatter map visualization

## Tools Used

- Python
- Pandas
- GeoPandas
- Folium
- Matplotlib
- Jupyter Notebook

## Files

- `geospatial_analysis.ipynb` — Main analysis notebook
- `geospatial_analysis.py` — Python script
- `geospatial_data.csv` — Dataset
- `heatmap.html` — Interactive heatmap
- `scatter_map.html` — Interactive scatter map
