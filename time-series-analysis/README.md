# Time Series Analysis and Forecasting

This is a time series forecasting project I completed as part of my Big Data Analytics course at United International University (UIU).

## About the Project

In this project, I worked with time series data and analyzed the pattern over time. I used Python and Jupyter Notebook to prepare the data, study the time series, and build a SARIMA model for forecasting.

## Tools Used

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- SARIMA
- Time Series Analysis

## What I Did

- Prepared the time series data
- Analyzed the data over time
- Worked with seasonal patterns
- Built a SARIMA forecasting model
- Compared the actual values with the forecast
- Evaluated the model using MAE and RMSE
- Created graphs to show the forecasting results

## Model Result

For the daily SARIMA forecast, the model produced:

- MAE: 11.98
- RMSE: 15.11

## Files

- `time_series.ipynb` — Main analysis notebook
- `time_series.py` — Python source code
- `seasonal_big_timeseries_5min_2023_2025.csv` — Dataset used for the analysis

## What I Learned

This project helped me understand how time series data can be analyzed and how forecasting models can be used to estimate future values.
