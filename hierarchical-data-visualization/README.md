# Hierarchical Data Visualization

This project is part of my Big Data Analytics coursework at United International University (UIU).

## About the Project

In this project, I worked with organizational data to explore salary patterns across different regions and divisions. I used data aggregation and visualization to make the results easier to understand.

## Analysis

The project includes visualizations such as:

- Total salary by region
- Salary distribution across divisions within regions
- Comparisons of organizational salary data

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset

The analysis uses an organizational dataset containing information about regions, divisions, and salary values.

## Files

- `hierarchical_data_visualization.ipynb` — Main Jupyter Notebook
- `hierarchical_data_visualization.py` — Python source code
- `hierarchical_bigdata_org.csv` — Dataset used for the analysis

## Purpose

The purpose of this project is to explore hierarchical data and present useful patterns through data visualization.
