# Text Analytics — Sentiment Analysis

This is one of my projects from the Big Data Analytics course at United International University (UIU).

## About the Project

In this project, I worked with customer review data to understand the sentiment expressed in the reviews. I used Python and Jupyter Notebook to process the data, calculate sentiment scores, and summarize the results.

## Tools Used

- Python
- Jupyter Notebook
- Pandas
- Microsoft Excel
- Data Visualization
- Sentiment Analysis

## What I Did

- Prepared and cleaned the review data
- Analyzed the sentiment of the reviews
- Created sentiment scores and summaries
- Checked the distribution of different sentiments
- Created visualizations to present the results

## Files

- `Sentiment_Analysis.ipynb` — Main notebook
- `Human_Review.xlsx` — Review data
- `sentiment_scored.xlsx` — Sentiment results
- `sentiment_summary.xlsx` — Summary results
- `sentiment_distribution.png` — Sentiment visualization

## What I Learned

This project helped me understand how text data can be processed and analyzed to find useful patterns from customer reviews.
